# Manual Link Inbox

Add public links to `inbox.csv` when you want the system to consider them.

Rules:
- Use only public links.
- Do not add client, prospect, NDA, private email, private Slack, internal strategy, or unannounced roadmap content.
- Manual LinkedIn or X links are allowed as signals only. They cannot support factual claims without a better source.

CSV columns:

```csv
url,title,source_hint,notes,added_at
```
