Optional phone approval setup

Press Optional Phone Setup only if you want Google Apps Script magic links.

1

Create the Google Sheet

Click Open New Google Sheet. In the new Google Sheet, rename the file to AI LinkedIn Review Queue. Rename the bottom tab from Sheet1 to ReviewQueue. Click cell A1, then paste the copied header row there.

Success looks like this: row 1 contains many column names, starting with review_id and draft_id.

2

Open Apps Script from that Sheet

Stay inside the Google Sheet. In the Google Sheet menu, click Extensions, then Apps Script. A new Apps Script browser tab opens. This is where the next three copied files go.

3

Replace Code.gs

In Apps Script, click Code.gs in the left file list. Select all starter code in that file, delete it, then paste the Code.gs content copied from this console.

Paste location: Apps Script editor -> Code.gs file.

4

Add Index.html

In Apps Script, click the plus button next to Files, choose HTML, and name it exactly Index. Apps Script will create Index.html. Paste the copied Index.html content into that new file.

Paste location: Apps Script editor -> new HTML file named Index.

5

Replace appsscript.json

In Apps Script, click Project Settings, turn on Show appsscript.json manifest file in editor, then return to the editor. Open appsscript.json, select everything, and paste the copied manifest.

Paste location: Apps Script editor -> appsscript.json file.

6

Deploy as a web app

First click Save in Apps Script. Unsaved Code.gs, Index.html, or appsscript.json changes can make Google show only API Executable. If this is your existing approval app, click Deploy, Manage deployments, the pencil icon, Version, New version, then Deploy. This keeps the same /exec URL you already saved.

If you are creating the approval app for the first time, click Deploy, then New deployment. Click the gear icon beside Select type and choose Web app.

If you still only see API Executable, close that popup, reload Apps Script, confirm Code.gs contains doGet, confirm appsscript.json contains a webapp block, save again, then open Deploy -> New deployment again.

Set Execute as to Me. For Who has access, choose Anyone if available, or Anyone with Google account if that is the only option in your consumer Google account. Click Deploy, authorize when Google asks, then copy the Web app URL that ends with /exec.

Important: this approval page records a decision in your Sheet. It does not publish to LinkedIn.

7

Save the web app URL here

Return to this AI LinkedIn Console tab. Paste the copied /exec URL into the field below. Press Save URL. Then press Mark Approval Page Deployed.
